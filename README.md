# Pohang EasyGo · 포항 이지 고

발달장애인의 공공기관 방문 준비, 이용 연습, 현장 의사소통을 돕는 서비스.

## 첫 구현 범위

- 신분증: 주민등록증 재발급
- 증명서: 주민등록등본 발급
- 복지: 상담 목적 정리와 방문 준비
- 도서관: 회원증 만들기

현재는 데이터 조사 단계다. 앱과 API 연동은 아직 구현하지 않았다.
화면 구현은 TypeScript + React를 예정하며 서버 구성은 연동 범위 확정 후 결정한다.

## 로컬 인증키

`.env.example`을 참고해 저장소 루트의 `.env`에 공공데이터포털 일반 인증키(Decoding)를 입력한다.
지자체는 `SSIS_LOCAL_WELFARE_SERVICE_KEY`, 중앙부처는 `SSIS_NATIONAL_WELFARE_SERVICE_KEY`다.
같은 인증키가 발급된 경우 두 변수에 같은 값을 입력한다. 서비스별 활용 승인은 각각 필요하다.
`.env`는 Git 제외 대상이며 실제 키를 예시 파일이나 채팅에 넣지 않는다.
키는 서버·로컬 수집 작업에서만 사용한다. `VITE_` 등 브라우저 공개 변수로 전달하지 않는다.
현재 앱과 환경변수 로더는 구현 전이므로 파일 작성만으로 API가 연결되는 것은 아니다.
