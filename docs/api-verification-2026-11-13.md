# 복지 API 최초 연결 확인

확인일: 2026-11-13, 한국시간. 로컬 `.env`의 키를 공식 HTTPS API에 전송했다.
키·인증 쿼리·원본 요청 URL·응답 원문은 문서에 저장하지 않았다.

## 확인 결과

| 요청 | HTTP | API 결과 | 응답 totalCount |
|---|---|---|---|
| 중앙부처 목록 1페이지·3건 | 200 | 0 / SUCCESS | 461 |
| 중앙부처 상세 WLF00000024 | 200 | 0 / SUCCESS | 해당 없음 |
| 지자체 목록: 경상북도·포항시, 1페이지·3건 | 200 | 0 / SUCCESS | 9 |
| 지자체 상세 WLF00002115 | 200 | 0 / SUCCESS | 해당 없음 |
| 지자체 목록: 경상북도, 1페이지·3건 | 200 | 0 / SUCCESS | 289 |
| 지자체 목록: 경상북도·포항시 남구 | 200 | 40 / NO DATA FOUND | 0 |
| 지자체 목록: 경상북도·포항시 북구 | 200 | 40 / NO DATA FOUND | 0 |
| 중앙부처 제목 검색: 장애인, 1페이지·3건 | 200 | 0 / SUCCESS | 54 |

총 8건을 확인했다. 성공한 목록은 각 3개 샘플만 받았으며 totalCount는 해당 조건에서 API가 보고한 전체 건수다.
이 값은 행정구역 전체 복지사업의 완전한 개수나 현재 접수 가능한 사업 수를 뜻하지 않는다.
남구/북구 결과 없음은 해당 검색 문자열의 응답이며 그 지역에 복지서비스가 없다는 뜻이 아니다.

## 샘플로 직접 확인한 내용

- 중앙부처 장애인 검색 예: 장애인자립자금대여, 장애인일자리지원, 장애인 운전교육 사업.
- 포항시 목록 예: 중.고등학교 신입생 교복구입비 지원, 보훈명예수당 지원, 참전명예수당 지원.
- 중앙부처 상세 샘플: 아이돌봄서비스. 서비스 ID·이름·지원대상 상세(`tgtrDtlCn`)·선정기준·지원내용의 값 존재 확인.
- 포항시 상세 샘플: 중.고등학교 신입생 교복구입비 지원. 서비스 ID·이름·지원대상(`sprtTrgtCn`)·선정기준·지원내용·신청방법(`aplyMtdCn`)의 값 존재 확인.
- 목록의 서비스 ID와 상세의 서비스 ID가 동일함을 확인했다.
- 경상북도 검색 샘플에는 다른 시군 사업이 포함됐다. 289건 전부를 포항 적용 사업으로 표시하면 안 된다.

## 연동에 반영할 점

- XML 응답이다. Orbit에서 나온 JSON 안내를 사용하지 않는다.
- 지역 검색은 우선 `ctpvNm=경상북도`, `sggNm=포항시`를 기준으로 삼는다.
- 지자체·중앙부처의 지원대상 필드명이 다르므로 원천별 변환이 필요하다.
- 포항 9건과 중앙부처 장애인 제목 검색 54건만으로 장애인 지원 범위를 완성했다고 볼 수 없다. 제목에 '장애인'이 없는 관련 사업이 있을 수 있다.
- 광역 단위 사업의 지역 표시, 전체 페이지, 중복·종료·누락은 후속 검토 대상이다.

## 재현 정보

중앙부처 기본 주소: `https://apis.data.go.kr/B554287/NationalWelfareInformationsV001`

- 목록: `/NationalWelfarelistV001`, `callTp=L`, `pageNo=1`, `numOfRows=3`, `srchKeyCode=001`.
- 상세: `/NationalWelfaredetailedV001`, `callTp=D`, `servId`.
- 제목 검색에는 `searchWrd=장애인` 추가.

지자체 기본 주소: `https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations`

- 목록: `/LcgvWelfarelist`, `pageNo=1`, `numOfRows=3`, 지역 조건.
- 상세: `/LcgvWelfaredetailed`, `servId`.

두 API 모두 `serviceKey`는 로컬 환경에서 읽고 요청 시 한 번 URL 인코딩한다. 인증키 포함 URL을 출력하지 않는다.
Postman api-testing 스킬의 계약 기반 확인 관점을 적용했고, 실제 요청은 인증정보의 CLI 인자·출력 노출을 피하려고 Python 표준 HTTPS/XML 도구로 수행했다.
임시 검증 스크립트 실행 종료 코드는 0이었다. 자동 회귀 테스트의 전체 통과를 뜻하지 않으며 위 HTTP/API 코드·샘플 필드를 확인한 연결 점검이다.
