# 데이터·API 조사

조사일: 2026-11-13 (한국시간)

후속 확인: 사용자가 키를 입력한 뒤 두 복지 API의 목록·상세 조회에 성공했다.
[최초 연결 검증 결과](api-verification-2026-11-13.md)를 참고한다. 아래의 호출 미실시 표기는 최초 조사 당시 상태다.

## 결론

첫 버전은 **공식 안내를 검토해 만든 업무별 콘텐츠 + 기관 기본 정보 + 선택적인 복지 API**로 구성한다.
네 가지 메뉴 전체를 채워 주는 단일 API는 이번 조사에서 확인하지 못했다.
조회형 공개 데이터와 실제 발급·신청 기능은 서로 다르다. 이번 범위는 준비·연습·현장 소통 지원이다.

**먼저 활용신청할 후보는 한국사회보장정보원의 지자체복지서비스와 중앙부처복지서비스 2개다.**
두 서비스는 복지 상담의 참고 정보를 보강한다. 상담 목적을 정리하는 초기 화면 자체의 필수 의존성은 아니다.
지도 API, 도서 검색 API, 신분 인증 API는 현재 발급을 보류한다.

## 확인 수준

- 문서 확인: 제공기관 또는 공식 데이터포털의 설명·메타데이터 확인.
- 인증 호출 미실시: 키가 없어 실제 응답·포항 데이터 건수·누락률은 확인하지 않음.
- 현장 미확인: 담당 창구·번호표·내부 동선·사진·직원 지원 방식은 확인하지 않음.
- 목록에 없다는 사실을 API가 존재하지 않는다는 증명으로 사용하지 않음.

## 1. 활용신청 후보

| 우선순위 | 이름·식별자 | 제공 내용 / 사용 목적 | 상태 |
|---|---|---|---|
| 먼저 신청 | [한국사회보장정보원_지자체복지서비스](https://www.data.go.kr/data/15108347/openapi.do), 15108347 | 목록·상세의 지원대상, 선정기준, 신청방법. 포항·경북 사업을 상담 참고 자료로 연결 | 공식 문서 확인, 실제 지역 검색 미실시 |
| 함께 신청 | [한국사회보장정보원_중앙부처복지서비스](https://www.data.go.kr/data/15090532/openapi.do), 15090532 | 전국 단위 복지사업 목록·상세. 지역 사업만으로 부족한 상담 참고 정보를 보강 | 공식 문서 확인, 실제 호출 미실시 |
| 보류 | [한국사회보장정보원_사회복지시설정보서비스 현황](https://www.data.go.kr/data/15001848/openapi.do), 15001848 | 시설 목록·기본정보. 복지시설 연결이 필요해질 때 검토 | 행정복지센터 전체 명부로 간주하지 않음 |
| 보류 | [행정안전부_대한민국 공공서비스(혜택) 정보](https://www.data.go.kr/data/15113968/openapi.do), 15113968 | 정부 혜택 목록·상세 | 복지 API와 범위 중복. 일반 민원 발급 절차 API로 사용하지 않음 |

위 네 데이터의 공식 메타데이터는 비용 무료, 이용허락범위 제한 없음으로 안내한다. 호출 제한이 없다는 뜻은 아니다.
앞의 복지 API 2개는 REST/XML로 안내하며, 이용허락범위의 상세 정책은 각 링크에서 재확인한다.

### 신청 방법과 요청할 정보

1. 공공데이터포털 로그인 후 위 **첫 두 개 서비스 각각**의 활용신청을 진행한다.
2. 용도 예시: `포항시 발달장애인의 공공서비스 이용 지원을 위해 복지사업의 지원대상·신청방법 등 공개 정보를 조회하고 쉬운 상담 준비 안내로 제공하는 웹서비스 개발`.
3. 승인 화면에서 상태, 개발계정 트래픽, 이용 기간, 최신 활용가이드·코드표를 확인한다.
4. 신청 완료 여부와 비밀정보를 가린 제한 정보만 공유한다. 키는 채팅·문서·Git에 넣지 않고 추후 로컬 `.env`에 보관한다.
5. 통합 인증키가 표시되더라도 서비스별 이용 승인과 호출 성공을 각각 확인한다.

**자동승인 여부·승인 소요시간·정확한 계정별 호출량은 이번 공식 문서 확인에서 확정하지 못했다.**
제3자 요약에 나오는 일일 호출량을 신청 계정의 보장값으로 사용하지 않는다.

### 문서에서 확인한 연동 단서

- 중앙부처 기본 주소: `https://apis.data.go.kr/B554287/NationalWelfareInformationsV001`
- 지자체 기본 주소: `https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations`
- 인증: `serviceKey` 요청변수.
- 중앙부처 목록: `callTp=L`, `pageNo`, `numOfRows`, `srchKeyCode`; 검색어 등 추가 조건 제공.
- 지자체 목록: `ctpvNm`, `sggNm` 지역 검색 조건 제공. 경상북도·포항시 및 남구/북구의 실제 값·결과는 승인 후 코드표와 응답으로 확인한다.
- 지역별 사업만 요청하면 광역 사업이 누락될 수 있으므로 경북 사업과 포항 사업의 포함 범위·중복을 함께 검사한다.
- 상세 API의 정확한 경로와 서비스 ID 연결, HTML/줄바꿈 포함 여부는 최신 가이드와 실제 응답으로 확정한다.
- 공개된 사업 조건은 상담 참고 정보다. 개인의 수급 자격 확정이나 신청 접수 성공을 뜻하지 않는다.

## 2. 메뉴별 데이터 확보 방식

### 신분증 — 주민등록증 재발급

- [정부24 공식 민원 안내](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13100000018&HighCtgCD=&tp_seq=01): 신청 경로, 서류, 비용·처리기간 등 절차의 기준 자료.
- [행정안전부 재발급 안내](https://mois.go.kr/frt/sub/a06/b06/IDCard_3/screen.do): 재발급 사유와 준비사항 교차 확인.
- [행정안전부 중증장애인 방문발급 안내](https://mois.go.kr/frt/sub/a06/b06/IDCard_4/screen.do): 직접 방문이 어려울 때 안내할 대안 후보.
- 구현: 확인된 내용을 사람이 구조화한 업무 파일로 관리. 최초 발급·재발급·모바일 신분증을 같은 절차로 섞지 않는다.
- 준비물·비용을 모든 사유에 동일하게 표시하지 않는다. 감면·대리신청·방문발급은 해당 여부를 기관에 확인하도록 연결한다.
- 이번 조사에서 상세 절차를 공급하는 적합한 공개 API는 미확인. 실제 재발급 접수·신분 진위확인 API는 범위 밖이다.

### 증명서 — 주민등록등본

- [정부24 주민등록표 등본(초본) 발급](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13100000015): 신청 경로·서류·처리 조건의 기준 자료.
- [포항시 구술민원 안내](https://pohang.go.kr/portal/contents.do?mid=0105070000): 등·초본과 주민등록증 재발급 등을 대상 목록에 명시.
- 구현: 첫 업무를 본인의 등본 방문 발급으로 좁히고, 대리 발급·초본은 별도 업무로 분리한다.
- 구술민원의 구체적인 진행·적용 조건은 선정 기관에 확인한다. 글을 직접 작성하는 흐름만 강요하지 않는다.
- 웹 조회 도중 정부24의 접속 대기·차단 안내가 함께 나타났으나 민원 본문도 확인했다. 수집 자동화가 가능하다는 뜻은 아니다.
- API 키 신청은 현재 불필요. 본인의 등본 원문·주민등록번호·신분증 사진을 수집하는 기능은 만들지 않는다.

### 복지 상담

- 위 복지 API 2개로 사업 정보를 보강한다. 예: 상담할 주제와 연결된 사업의 공식 설명·신청 경로를 제시.
- 실제 상담 장소·전화·접수 방식은 선정한 행정복지센터의 공식 안내와 담당자 확인으로 관리한다.
- 초기 기능: 어려움 선택 → 이용자가 확인한 상담 목적 정리 → 가져갈 질문·도움 요청 카드.
- 소득·재산을 받아 자동 수급 판정을 하거나 실시간 상담 예약·접수를 완료했다고 표시하지 않는다.

### 도서관 — 회원증 만들기

- [전국도서관표준데이터](https://www.data.go.kr/data/15013109/standard.do), 15013109: 도서관명, 주소, 전화, 운영시간, 휴관일, 홈페이지, 좌표 등.
- 메타데이터 갱신 주기는 연간이다. 당일 임시휴관·특별 운영을 보장하지 않으므로 기관 공지와 대조한다.
- [포항시립도서관 공식 홈페이지](https://phlib.pohang.go.kr/): 이번 조사 도구에서는 웹 방화벽으로 본문 접근이 막혔다. 회원증 발급 조건은 아직 공식 본문 대조 미완료.
- 구현: 처음에는 표준데이터 파일 내려받기 방식을 우선 검토하고 포항 행을 추린 뒤 선정 기관과 대조한다. 파일의 실제 포항 행 수와 완전성은 아직 미확인.
- 표준데이터에는 회원증 발급 절차·상세 준비물·실내 사진이 포함된다고 볼 수 없다.
- 포항봇의 답변과 블로그 요약은 최종 절차의 확정 근거로 쓰지 않는다.
- 도서 검색·대출이력·회원 인증 API는 이번 회원증 준비·연습 범위에 필요하지 않다.

## 3. 기관 위치·지도

- 포항시 행정복지센터 목록 API의 존재를 암시하는 제3자 목록은 발견했으나 최신 공식 서비스 ID·문서를 확인하지 못했다. **발급 요청 대상에서 제외**한다.
- 선정 기관은 포항시 공식 누리집의 읍면동 안내·찾아오시는 길과 기관 확인으로 등록한다.
- 도서관 위치는 표준데이터를 우선 검토한다.
- [Kakao Local 공식 문서](https://developers.kakao.com/docs/ko/local/dev-guide): 주소·장소 검색 및 좌표 확인의 확장 후보.
- [Kakao Maps Web 공식 가이드](https://apis.map.kakao.com/web/guide/): 지도 표시의 확장 후보.
- 첫 버전은 주소·전화·외부 지도 링크로 진행 가능하므로 지금 지도 키 발급은 필요 없다.
- 지도 검색 결과만으로 해당 기관이 특정 업무를 처리한다고 확정하거나, 출입구·실내 창구 위치를 추정하지 않는다.
- 임베디드 지도·검색을 추가할 때 키 종류, 도메인 등록, 활성화·쿼터·요금 조건을 다시 확인한다.

## 4. 직접 확보·검토할 자료

| 자료 | 확보 방법 | 아직 모르는 것 |
|---|---|---|
| 기관 입구·창구 사진 | 기관 허락 후 직접 촬영 또는 이용허락이 명확한 제공 사진 | 촬영·게시 가능 여부 |
| 번호표·접수·이동 순서 | 선정 기관 담당자 확인 | 창구별 절차·예외 |
| 업무별 쉬운 설명 | 공식 자료에서 초안 작성, AI 보조, 사람 검토 | 실제 이해도 |
| 도움 요청 문장 | 당사자·지원자 의견으로 검토 | 선호 표현·선택 방식 |
| 상황 연습 | 실제로 막히는 사례를 확인해 시나리오 작성 | 빈번한 어려움·필요성 |

공식 페이지 공개 여부와 사진·도표의 재사용 허락은 별개다. 원문을 대량 복사하거나 차단을 우회하지 않는다.
쉬운 글·그림 도구의 기존 콘텐츠를 허락 없이 가져오지 않고 직접 작성·제작하거나 허용된 자료를 사용한다.

## 5. 데이터 구조와 갱신 제안

공통 필드: `source_id`, 원문 URL, 제공기관, 원문 변경일(알 수 있을 때), 실제 확인일, 재확인 예정일, 검토 상태.

- 기관: 이름, 주소, 연락처, 좌표(선택), 담당 업무, 운영 안내, 사진 권리·확인 기록.
- 업무: 이용 조건, 경우별 준비물, 신청 경로, 비용 조건, 단계, 예외, 도움 요청, 근거 source ID.
- 연습: 업무·기관 ID, 상황, 선택지, 다음 행동, 설명, 사람 검토 여부.
- 복지: 원천 서비스 ID, 기관·지역 범위, 지원대상, 신청방법, 출처 링크, 조회 시각.

`미확인 / 공식자료 확인 / 기관 확인 / 이용자 검토` 상태를 구분한다. API 갱신 성공을 현장 검토 완료로 취급하지 않는다.
복지 목록은 서버에서 정기적으로 갱신하는 방식을 검토하되 최초 호출량을 보고 주기를 정한다. 상세는 필요 시 조회·캐시한다.
핵심 안내문은 원문 변경 시 재검토하고, 검토 전 새 AI 문장을 자동 게시하지 않는다.

## 6. 승인 후 내가 수행할 확인

1. 각 API의 최소 목록·상세 호출과 인증·오류 응답을 확인한다.
2. 응답을 XML 기준으로 읽고, 서비스 ID와 상세 조회 연결을 확인한다.
3. 경북·포항·남구/북구 검색 결과를 비교해 지역 범위와 누락 가능성을 기록한다.
4. 장애 관련 사업 몇 건의 지원대상·신청 경로를 원문과 대조한다.
5. 문서·응답 차이와 계정 호출량을 반영해 필요한 API만 유지한다.
6. 인증값을 제거한 샘플과 검증 결과를 기록한 뒤 화면 구현으로 넘어간다.

## 조사 도구와 한계

Postman api-discovery 스킬의 Orbit 검색·통합 안내와 공식 웹 문서를 사용했다.
Orbit 중앙부처 후보 ID: `urn:orbit:endpoint:v1:aNItF6YWKb8B1HHIYYJbKrfvTeOwlfai:open:national-welfare-informa`.
Orbit 안내는 JSON 예시를 제시했지만 공식 데이터포털은 XML로 안내했다. **공식 문서를 우선하고 실제 응답 확인 전 JSON을 가정하지 않는다.**
Postman 계정의 비공개 컬렉션·Context Graph 검색은 사용하지 않았다. 현재 API 호출 코드·실행 가능한 계약·mock은 만들지 않았다.
이 문서는 제공 범위 조사이며, 호환성·실제 호출 성공·데이터 완전성을 검증한 결과가 아니다.
